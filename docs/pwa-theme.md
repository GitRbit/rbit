# Installed app colors

The installed app uses the chosen rbit theme for its launch background and app chrome. System mode uses rbit Light or rbit Dark to match the device. Changing themes updates the manifest link. The app ID stays `/`, so a color change does not create a second app.

The maskable and iOS icons use the rbit Light canvas instead of beige. Browsers choose when to refresh an installed app's manifest and icons; an existing install may show old colors until it refreshes.
