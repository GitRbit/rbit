# Create a repository

Use the Empty, Mirror and Import tabs on the new repository page. Tabs load each form once, then keep it in the page. Owner, name, description and visibility carry across the forms that support them. Mirror URLs, fetch intervals and import options stay with their own tab.

Switching tabs keeps drafts in the current page only. Submitting a form uses the same server route and access checks as before. If a tab cannot load, it shows a retry message and keeps your current form. Without JavaScript, the tabs open each form as a page.
