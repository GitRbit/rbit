# Discussions

Issues and pull requests share a comment editor. Reply adds a link to the source comment, mentions its author and quotes its text. It keeps any draft you have typed. The quote stays in the comment after you post it, even if the source changes later.

Type `@` to find a user or organization, or `#` to find an issue or pull request in this repository. Type a name, title word or thread number to narrow the list. Use the arrow keys and Enter to choose, or Escape to close. You can also type `owner/repo#123` to link a thread elsewhere.

Mention searches return at most ten choices. Thread choices use the same repository access check as the discussion page. Comment, lock and state rules still apply when you post. Without JavaScript, you can type mentions and Markdown quotes yourself.
