# Pull request files

The Files changed tab shares the file tree used by commit and compare pages. On wide screens it stays beside the diffs and marks the file in view. Toggle the tree to give diffs more room; the browser remembers that choice. On phones, open File tree above the diffs and choose a file to close the tree and jump to its diff.

Filter files by words in their paths. Press Enter to open the first match or Escape to clear the filter. Folders can collapse, and Collapse all folds the file diffs. Following a file link opens its diff again. Without JavaScript, the tree still links to each file and each diff can open or close.

File links keep the same anchors used by line comments. Opening a comment form or posting a review reply still uses the existing review flow. Large and binary files keep their placeholders, and large text diffs keep their offscreen blocks.
