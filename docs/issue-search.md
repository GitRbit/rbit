# Issue search

Search titles and descriptions with the search box. Press Search or Enter to submit.
Open Author, Label, Milestone, Assignee or Sort to choose a filter. Type in a menu to find a choice. Each choice keeps the other filters and resets the page.

Use Any label to clear label filters, or No labels to find unlabelled threads. Search help lists terms you can type, including quoted label names and `author:@me`.

Pull requests use the same search box, menus and sort choices. Use `is:draft` or `is:merged` to narrow pull requests. The pull request list always searches pull requests, even if a pasted query includes `is:issue`. Old `state` and `author` links still work.
