Access tokens

Use a token instead of your password for Git over HTTPS: enter your username {{ username }} and paste the token when Git asks for a password. The REST API at /api/v1 takes it as Authorization: Bearer. Tokens start with rbit_; tokens from earlier releases start with rit_ and keep working.
